# Proposal

## Why

Isac selected Ibrahim Memon's Figma Portfolio as the visual direction for his portfolio. The current warm editorial design should become a dark purple developer portfolio while retaining the site's verified resume content and accessible recruiter journeys.

## What Changes

- Replace the warm palette and serif headings with a deep purple canvas, Poppins typography, lavender accents, atmospheric glows, and gradient cards.
- Compose the home page around an original developer illustration, Isac's name and handle, Backend Engineer / SDET headline, current internship, experience and focus cards, a skills constellation, selected work, and contact.
- Apply the same visual language to Work, About, Resume, project details, 404, navigation, footer, and social artwork.
- Keep the approved PDF and email, keyboard behavior, reduced-motion support, static rendering, and draft exclusions functional.
- Create original artwork and markup as a remix of the reference; do not import its personal assets, project claims, or booking/analytics integrations.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `portfolio-experience`: replace the editorial presentation requirement with the selected purple visual system and specify the home page's sourced experience and skills presentation.

## Impact

Astro pages and shared components, global styles, local fonts, original SVG artwork, social metadata colors, browser coverage, and design documentation. No runtime backend, route removal, new public project claims, AWS deployment, or resume document regeneration is required.
